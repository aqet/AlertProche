Installer AlertProche sur iPhone / iPad

Suivez ces 3 étapes dans Safari pour ajouter l'app à votre écran d'accueil :

  1. 1
    Appuyez sur le bouton Partager L'icône en bas de Safari
  2. 2
    Faites défiler et appuyez sur « Sur l'écran d'accueil »
  3. 3
    Appuyez sur « Ajouter » L'icône AlertProche apparaîtra sur votre écran d'accueil
Fonctionne uniquement depuis Safari sur iOS
